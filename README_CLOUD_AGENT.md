## 🎯 What This Does

This Cloud Agent runs **daily** (11:15 UTC) to:

1. 🔍 **Research** eCommerce opportunities in Uruguay (construction/waterproofing)
2. 🔐 **Scan** all your GitHub repos + branches for .env keys (keys-only, secure)
3. 📊 **Report** findings in a daily GitHub issue
4. 📦 **Publish** artifacts (JSON/MD) for download
5. 💾 **Update** unified .env template automatically

---

## ⚡ Quick Start (3 Steps)

### Step 1: Create GitHub Token (2 minutes)

1. Go to: https://github.com/settings/tokens?type=beta
2. Click **"Generate new token"**
3. Configure:
   - **Name**: Cloud Agent Read-Only
   - **Expiration**: 90 days
   - **Repository access**: All repositories
   - **Permissions**: Contents = **Read-only** ✅
4. Generate and **copy the token**

### Step 2: Add GitHub Secrets (1 minute)

1. Go to: **Settings → Secrets and variables → Actions**
2. Click **"New repository secret"**
3. Add two secrets:

```
Name: GH_OWNER
Value: matiasportugau-ui

Name: GH_SCAN_TOKEN
Value: <paste-token-from-step-1>
```

### Step 3: Run First Workflow (2 minutes)

1. Go to: **Actions → cloud-agent-daily**
2. Click **"Run workflow"** button
3. Wait 2-5 minutes
4. Check outputs:
   - ✅ Artifacts: cloud-agent-output (download ZIP)
   - ✅ Issue: "Cloud Agent Daily - 2025-12-14"
   - ✅ Commit: env/.env.unified.example updated

## 🎛️ Quick Configuration

### Change Schedule
Edit `.github/workflows/cloud-agent-daily.yml`:
```yaml
cron: "15 11 * * *"  # 11:15 UTC (change time here)
```

### Tune Performance
```yaml
BRANCH_LIMIT: "50"    # Reduce if slow (try 20)
BRANCH_ALLOW_REGEX: "^(main|master|develop)"  # Fewer branches
```

### Adjust Focus
```yaml
MARKET: "Uruguay"     # Change country
FOCUS: "..."          # Change product categories
```

### Update Scoring
Edit `config/weights.yml`:
```yaml
demanda: 0.35         # How important is demand?
margen_potencial: 0.25  # How important is margin?
# (must sum to 1.0)
```

## 🚨 Troubleshooting

| Problem | Solution |
|---------|----------|
| Workflow fails: "Missing GH_SCAN_TOKEN" | Add secrets (Step 2 above) |
| Workflow times out (>10 min) | Reduce `BRANCH_LIMIT` to 20 |
| Rate limit errors (403) | Wait 1 hour, or reduce scan scope |
| No .env files found | Normal - check artifact for details |
